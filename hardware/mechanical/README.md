# Mechanical

Parts are generated by Python scripts run in Fusion 360 through the FusionBridge add-in ([fusion/README.md](fusion/README.md)),
checked there, and exported as STLs. One version of each part is kept; older ones are in the Git history.

| Part | Generator | Build script | Print files and docs |
|---|---|---|---|
| **Tilter** | [`fusion/Tilter/Tilter.py`](fusion/Tilter/Tilter.py) (pure geometry in `gear_geom.py`, Fusion helpers and the worm in `tilt_base.py`) | `tools/fusion_tilter.py`, then `tools/fusion_thin.py` | [`stl/tilter/`](stl/tilter/README.md) |
| **Controller box** | [`fusion/Controller/Controller.py`](fusion/Controller/Controller.py) | `tools/fusion_controller.py` | `stl/controller/`, [docs/controller-box.md](../../docs/controller-box.md) |

Print files: `python3 tools/orient.py && python3 tools/bambu.py` writes `stl/tilter/print/` and the Bambu Studio projects.

## Known dimensions
| What | Value |
|---|---|
| Headrail inner width × height | about 55.5 × 36.5 mm, 2 mm plastic walls, lips 4.5 mm in at the top |
| Tilt rod | 4 mm square steel, axis 24 mm above the inner floor, centered. A crimp stops it about 21 mm into the tilter |
| Free length, end cap to first tilt drum | 110 mm |
| Clearance above the installed headrail | about 6.5 mm: nothing may stick up more than about 5 mm |

## Materials
Housing in PLA. Parts that rub or mesh against PLA all the time in PETG. Grease the gears with Super Lube 21030.
