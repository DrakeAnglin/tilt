# Mechanical

All parts are generated by Python scripts run in Fusion 360 through the FusionBridge add-in
([fusion/README.md](fusion/README.md)), checked there (interference, gear sweeps, wall thickness, overhangs) and exported
as STLs.

## Materials
PLA is fine for test fits. For the install, PETG is safer for anything in a sunny headrail (PLA softens near 55 °C).
Print the worm and the worm wheel in different plastics. Grease the gears with Super Lube 21030.
