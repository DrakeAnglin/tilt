# Tilt: the iPhone app

SwiftUI app in [Tilt](Tilt) with a Home Screen widget and Control Center buttons. No server: the phone talks straight
to each controller over a secured channel on Wi-Fi, and sets up a new controller over Bluetooth.

- `Tilt/Tilt/`: the app. `Tilt/Shared/`: code shared with the widget. `Tilt/TiltWidget/`: the widget and controls.
- Open `Tilt/Tilt.xcodeproj` in Xcode and run the `Tilt` scheme.
